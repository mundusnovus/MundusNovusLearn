Swift: Zero to Hero 2.0

One app for iPhone, iPad and Mac: 173 lessons in 10 chapters, 83 exercises, 82 quizzes, and a small on-device engine that checks your code without sending it anywhere. The Mac uses its own Swift compiler. The app is in App Store review; the web course is free and open now.

See the app Start the free course

What 2.0 does

  • Checked on device. iPhone and iPad use a parser, a teaching-subset interpreter and the lesson’s own tests. No network, no account, no upload. The Mac uses the real Swift compiler when it is available.
  • An honest limit. 61 of 83 exercises are checked fully on device. The other 22 open as Xcode labs, with the tests and starting code shown. Nothing is silently marked wrong.
  • Apple Intelligence, without the answers. A coach explains the error, a review suggests one improvement, a recap asks three questions, and a mini-lesson can be kept in My Lessons with a scratch editor.
  • A plan, not a guilt trip. The week is chosen from your progress alone. Apple Intelligence only adds the encouragement, so it cannot point at a lesson that does not exist.
  • Siri, Spotlight and Handoff. Continue the course, open a lesson, or ask how far you have got. The open lesson travels between devices.
  • iCloud progress. Lessons, code, checklist ticks, streaks and badges sync through your private iCloud. If it is unavailable, everything still works locally and Settings says so.

What you need

The app is built for iOS 27 and macOS 27. The Mac exercises need Apple’s free Command Line Tools or Xcode; the app offers to install them if they are missing. The web course needs a browser and a pulse.

Still free on the web

The browser course is available now and does not need an account. It uses the same lessons and the same tests, with the runner on the server. Open the course or read the privacy policy.

The Mac App Store app is in review. A store link will appear on asteria.technology/swift when it is available. Until then, the web course is the free version and the 1.0 Mac app remains available for older systems.
